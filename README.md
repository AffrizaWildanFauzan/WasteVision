# ♻️ Waste Classification App - BDC 2026

Aplikasi web untuk klasifikasi sampah menjadi 3 kategori menggunakan model **ConvNeXt-Large**.

## 📋 Kategori
1. **Recyclable** (♻️ Daur Ulang) - Kertas, plastik, kaca, logam
2. **Electronic** (💻 Elektronik) - Ponsel, laptop, baterai, komponen elektronik
3. **Organic** (🌿 Organik) - Sisa makanan, daun, limbah dapur

## 🚀 Fitur
- 📤 Upload gambar dengan drag & drop
- 🧠 Klasifikasi real-time dengan ConvNeXt-Large
- 📊 Visualisasi probabilitas per kelas
- 📥 Download hasil klasifikasi (JSON)
- 📱 Responsive design
- 💾 Penyimpanan file lokal (tanpa cloud)

## 🛠️ Teknologi

### Backend
- **Framework**: Flask 2.3.3
- **Deep Learning**: PyTorch 2.0.0
- **Model**: ConvNeXt-Large (timm)

### Frontend
- **HTML5**, **CSS3**, **JavaScript**
- **Font**: Inter
